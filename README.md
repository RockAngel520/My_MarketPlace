# My Marketplace - Интернет-магазин

Проект интернет-магазина, разрабатываемый в рамках учебного курса. Проект будет дорабатываться на каждом уроке в течение всего курса.

## Технологии

- **Python** 3.13
- **Django** - веб-фреймворк
- **Bootstrap** - CSS-фреймворк для стилизации

## Установка и запуск

### Предварительные требования

Установите Poetry, если еще не установлен:
   ```
    pip install poetry
   ```
### Установка проекта

1. **Клонирование репозитория**
   ```
   git clone https://github.com/RockAngel520/My_MarketPlace
   cd My_MarketPlace
   ```
   
2. **Установка зависимостей через Poetry**
    ```
    poetry install
   ```

3. **Активация виртуального окружения Poetry**
    ```
    poetry shell
    ```
   
4. **Применение миграций**
    ```
    python manage.py migrate
    ```
   
5. **Запуск сервера разработки**
    ```
    python manage.py runserver
    ```
   
6. **Открытие в браузере**
    ```
    http://127.0.0.1:8000/
    ```
   
## Функциональность
### На текущий момент реализовано:
- Главная страница (/) - домашняя страница магазина
